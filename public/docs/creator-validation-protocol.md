# X News Toolbox 真实创作者验证协议

目标：用同一套步骤记录 3–5 名真实创作者各两轮使用结果，证明工具是否节省时间、内容是否可用，以及 Mind 记忆是否改善第二轮结果。

## 测试前准备

- 每位参与者使用代号，不记录真实姓名、账号密码或 API Key。
- 参与者选择自己真实会发布内容的 X 或小红书平台。
- 准备一个真实选题和可访问的真实信息来源。
- 第一轮开始前记录参与者完成同类工作的通常耗时，作为“原流程耗时”。
- 不向参与者预设“推荐有用”等正面答案。

## 第一轮

1. 在信息雷达运行一次真实采集与 Mind 选题。
2. 让参与者判断推荐是否有用，并选择一条内容。
3. 选择一个目标平台，只生成该平台的草稿。
4. 让参与者审核、编辑或拒绝草稿；记录从开始到获得可审核草稿的分钟数。
5. 记录内容是否采用或进入发布准备、平台适配评分以及修改原因。
6. 如内容真实发布，登记真实发布文本、链接和当时可获得的指标。
7. 让 Mind 提议一条下一轮可验证的记忆；由参与者接受、编辑或拒绝。
8. 在 `/proof` 的“真实创作者验证”表单保存第一轮结果。

## 第二轮

1. 使用同一参与者的另一个真实选题，至少间隔到已接受记忆进入下一次调用。
2. 重复真实采集、Mind 选题、单平台生成和人工审核。
3. 确认界面显示本轮使用的 `usedMemoryIds` 和 `memoryInfluence`。
4. 记录本轮耗时、推荐是否有用、采用情况、平台适配评分和修改原因。
5. 请参与者用一句话说明“Mind 记住后明显改善了什么”；若没有改善，应如实填写“没有”。
6. 在 `/proof` 保存第二轮结果，并检查该参与者计入“完成两轮”。

## 合格证据

- 至少 3 名不同创作者完成两轮，建议 5 名。
- 中位耗时降低至少 30%。
- 至少 60% 的内容被采用或进入发布准备。
- 至少一名真实用户能指出一项由 Mind 记忆带来的第二轮改善。
- 所有比赛证明均来自 `live` 数据；`demo` 和 `replay` 只能作为补充说明。

## 隐私与真实性

- 参与者代号不得包含真实姓名、邮箱、手机号或社交账号。
- 不上传私密草稿、API Key、Cookie 或未公开的商业指标。
- 不为了达标修改用户原始评价；负面反馈同样保留。
- 发布指标由创作者手工录入，并在比赛材料中注明采集时间。
